# Delaware US Address API

Backend-only JSON API for generating Delaware, United States address records.

## Base URL

Use the deployed API host:

```text
https://api.vsakura.top
```

Local development:

```text
http://127.0.0.1:4300
```

## Rules

- This API only supports Delaware addresses.
- `state` is optional. If provided, it must be `DE` or `Delaware`.
- Other states return `400`.
- No page/UI is involved.
- The API returns JSON only.
- Address data is generated by reverse geocoding random Delaware coordinates through OpenStreetMap Nominatim.
- Person names are fetched from `randomuser.me` when enabled, with local fallback names.

## Endpoints

### List Supported States

```http
GET /api/public/us-address/states
```

Response:

```json
{
  "items": [
    {
      "full": "Delaware",
      "abbr": "DE"
    }
  ]
}
```

### Generate Delaware Address

```http
GET /api/public/us-address/generate
POST /api/public/us-address/generate
```

Query/body parameters:

| Name | Type | Required | Default | Notes |
| --- | --- | --- | --- | --- |
| `state` | string | no | `DE` | Only `DE` or `Delaware` is accepted. |
| `count` | integer | no | `1` | Range: `1` to `5`. |
| `includePerson` | boolean | no | `true` | Set `false` to return address only. |
| `attempts` | integer | no | `8` | Range: `1` to `12`; retry attempts per generated address. |

GET example:

```bash
curl "https://api.vsakura.top/api/public/us-address/generate?count=1"
```

POST example:

```bash
curl -X POST "https://api.vsakura.top/api/public/us-address/generate" \
  -H "Content-Type: application/json" \
  -d '{"count":1,"includePerson":true}'
```

## Errors

Unsupported state:

```http
400 Bad Request
```

```json
{
  "success": false,
  "message": "该接口只支持 Delaware 州地址，请使用 DE 或 Delaware"
}
```

Invalid parameters:

```http
400 Bad Request
```

```json
{
  "success": false,
  "message": "参数无效",
  "issues": [
    {
      "path": "count",
      "message": "Too big: expected number to be <=5"
    }
  ]
}
```

Upstream generation failed:

```http
502 Bad Gateway
```

```json
{
  "success": false,
  "code": "ADDRESS_GENERATION_FAILED",
  "message": "暂时无法生成美国地址，请稍后重试",
  "error": "Unable to generate a real address for DE"
}
```

## AI Usage Notes

For most callers, use:

```text
GET https://api.vsakura.top/api/public/us-address/generate?count=1
```

Read the first result from:

```text
items[0].address.fullAddress
```

Use these common fields:

```text
items[0].person.name
items[0].person.phone
items[0].address.street
items[0].address.city
items[0].address.state
items[0].address.zipCode
items[0].address.fullAddress
```
