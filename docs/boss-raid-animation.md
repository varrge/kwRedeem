# Boss 动画素材与接入

8 个素材位均已替换为有独立轮廓的角色，早期几何造型已移除。它们使用透明 WebP 图集，在 SVG 裁切视窗中逐帧播放。播放器按每只角色的实际帧尺寸、数量和时长运行，不使用 Spine 运行库或整图呼吸缩放。

每个 `web/assets/raid-<key>/CREDITS.md` 记录确切来源、作者、授权和改编内容。深渊之瞳是从授权静态模型制作的动作；符文巨像是从授权分件立绘制作的动作；其余使用原作者的动作序列。术士狂暴阶段复用待机并加快，不声称源素材有额外动作。素材来自不同作者，手绘、卡通与预渲染风格仍有差异，并非统一美术团队制作。亡骸源素材分辨率较低，已保留原尺寸避免宣称高清。

无需新增运行库，素材随项目发布。内置图片生成工具不可用，本次没有使用 AI 图片生成或付费 API。

## 预览

直接用浏览器打开 `web/boss-raid-animation-preview.html`，无需登录或启动本地服务。可切换全部 8 个角色，模拟受击、调整血量、确认击败、中止、重置和暂停。

预览页使用独立模拟数据，不访问 API，不会加入活动、生成伤害或改变奖励。正式入口仍是 `web/sub2api-raid.html`。

## 动画状态

| 服务端事实 | 展示 |
| --- | --- |
| 当前 Boss 正常存活 | 各角色自己的待机序列 |
| 同一 Boss 累计伤害增加 | 按差量播放一次受击和飘字，同一分钟 ID 不变也可显示新增量 |
| 剩余血量不高于 25% | 进入各自战斗姿态，仅视觉变化 |
| 血量归零或 Boss 正在结算 | 濒临击败，等待结算，保持存活动作 |
| 服务端确认 `defeated` | 播放该角色的倒地、崩解或坍缩动作；首次查看历史结果直接显示实际末帧 |
| 旧 Boss 确认击败且下一只已开启 | 等待角色自己的死亡动画完成事件再切换；图集加载失败直接切换，卡住最多等待8秒 |
| 月末未击败或活动中止 | 休眠；已击败 Boss 仍保持击败姿态 |

首次加载、相同数据刷新、伤害减少的校正、切换 Boss 和恢复后台页面均不补播历史受击。轮询不会重建同一 Boss 的 SVG。

## 文件与维护

- `web/raid-boss.js`：8 个角色目录、图集播放器、异步加载保护及显示状态。
- `web/raid-boss.css`：画面调色、减少动态和战场布局适配。
- `web/boss-raid-animation-preview.html`：离线素材及动作预览。
- `web/sub2api-raid.html`：读取原服务端状态驱动显示，保留原图片作为动画脚本未加载时的回退，并相应显示原作者署名。

活动月份、血量、伤害倍率、充值奖励与月末恢复逻辑均由原 API 管理。本次没有修改后端或活动配置。

页面隐藏或角色离开视口时暂停角色动画；战场粒子也暂停。支持系统减少动态偏好和用户按钮，按钮设置保存在浏览器中。

部署时应一起发布以上4个网页文件和全部8个 `web/assets/raid-*/` 目录，同时更新管理后台素材名称。先发布素材/CSS/JS再发布正式入口，避免入口先到而资源缺失。旧JPG继续保留供脚本回退使用；图集加载失败时保留同造型静态预览。无需数据库迁移。

素材按当前角色和当前动作加载，不在进入战场时预载全部图集。动作之间沿用固定坐标，图集外使用显式 clipPath，避免露出相邻帧；异步旧动作不能覆盖新动作或新 Boss。暂停后不累积后台时间。来源署名随当前角色切换，预览页同时提供每套素材的改编说明入口。
