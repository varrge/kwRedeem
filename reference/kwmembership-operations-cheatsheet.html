Quick reference

kwMembership Go 运维速查

只包含日常最常用的安全命令。默认不改变付款 Gate。

固定位置

用途位置
Go 项目/opt/kwmembership
Go 运行参数/etc/kwmembership.env
kwRedeem 项目/var/local/1panel/apps/openresty/openresty/www/sites/key/index
共享数据库…/index/data/kawang.db
服务kwmembership-worker.service

健康检查

sudo systemctl status kwmembership-worker --no-pager
sudo systemctl is-active kwmembership-worker
sudo journalctl -u kwmembership-worker -n 100 --no-pager

安全自检

sudo bash -lc '
  set -a
  source /etc/kwmembership.env
  set +a
  cd /opt/kwmembership
  ./bin/kwmembership-worker --check
'

成功标志：输出 shared kwRedeem database configuration is valid。该检查只打开共享数据库并启动一次 about:blank 无界面 Chrome，不领取订单。

改完运行参数后

sudo systemctl restart kwmembership-worker
sudo systemctl status kwmembership-worker --no-pager
