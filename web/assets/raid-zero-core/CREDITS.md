# 深渊之瞳 — Demonic Eye

The original hand-painted textured model is not supplied with animation. KaWang added eye rotation, oscillating nerve strands, hurt recoil and a shrinking/collapsing death pose, then pre-rendered the result to transparent frames. The final collapsed object remains visible; no external runtime or3D library is shipped to the client.

Rendering uses the original OBJ, UVs and256×256 diffuse texture. The eye surface is spherically subdivided for a smoother contour; nerve strands retain their source shape. A perspective camera, soft hemisphere/key/rim lighting, and ACES tone mapping are added. The four clips contain36 /30 /15 /30 frames and run for3s /2s /0.9s /2s. They use a common crop, six-column WebP atlases and a static poster; dimensions and timing are in `metadata.json`.

Changes: original model/texture by Grefuntor; animation, lighting, framing and WebP conversion by KaWang. The webpage applies its own brightness/saturation grading. Attribution and this changes notice must accompany distribution.
